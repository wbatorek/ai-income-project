# Products

One folder per product: `products/<short-name>/`.

Each product moves through these stages, with operator approval at the gates marked ✋:

1. **Idea:** niche, problem, target buyer, where buyers gather
2. **Validation ✋:** demand evidence, competitors, price points. The operator approves the niche
3. **Development:** outline, AI-generated draft, editing, design
4. **Review ✋:** the operator signs off on quality before publishing
5. **Launch ✋:** listing, price, delivery setup. The operator approves publishing and any posts in communities
6. **Results:** sales, refunds, feedback, next iteration

Suggested files per product: `idea.md`, `validation.md`, `outline.md`, `assets/`, `launch.md`, `results.md`.
