# Course knowledge: AI Income Challenge

Everything in this folder comes from the **AI Income Challenge** (host: Iman Gadzhi,
co-host: Mark Tilbury, Nov 7–16, 2026). It's what the course teaches, **not** independently checked.

Keep in mind the host co-owns Whop and sells paid coaching. Income figures in the course are
hand-picked success stories. Anything we act on should be checked in [`../research/`](../research/).

## Structure

| Folder | What | Use it for |
|---|---|---|
| [`knowledge/`](knowledge/) | **Valuable knowledge only**, sorted by topic and added to across sessions. No pitch, no motivation | **Start here.** This is what the system and products are built on |
| [`sessions/`](sessions/) | One file per session: summary, a **segment map** (what was taught when, and what was pitch or motivation), analysis | Context, and finding where something was said |
| [`transcripts/`](transcripts/) | Full transcripts split into labelled segments | Going back to the source, or re-analysis by agents |
| [`workbooks/`](workbooks/) | Filled-in workbooks | Reference |

## How each session is processed

1. **Segment** the full transcript into consecutive parts and label each one:
   - `LESSON`: teachable method, framework, process or demo → **valuable**
   - `EXAMPLE`: a concrete product or case that shows a method (niche, format, price) → **valuable**
   - `PROOF`: testimonials and income claims → summarized in one line, unverified
   - `PITCH`: offer, waitlist, scarcity, upsell → summarized in one line
   - `MOTIVATION`: mindset, stories, hype → summarized in one line
   - `LOGISTICS`: schedule, giveaways, passwords → only the facts
2. Save the labelled transcript to `transcripts/NN-<name>.md`, with a segment table at the top
   (time range, label, value 0–3, one-line summary).
3. Pull `LESSON` and `EXAMPLE` content into the topic files in `knowledge/`, citing the session
   and time, e.g. `(02-main ~01:35)`.
4. Write the session file in `sessions/`, with a short verdict on how much of the session was
   valuable.
